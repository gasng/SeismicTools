Well Logging Classification (WLC)

Инструмент для визуализации и классификации данных каротажа скважин

Это приложение предназначено для загрузки LAS-файлов, визуализирования кривых каротажа, постройки кросс-плотов и выполнение интерактивной классификации пластов с помощью полигонов.

ОСНОВНЫЕ ВОЗМОЖНОСТИ

Загрузка LAS-файлов — поддержка стандартного формата данных каротажа
Просмотр каротажа — отображение всех кривых с информацией о мин/макс значениях
Кросс-плоты — визуализация взаимосвязи между двумя кривыми
Интерактивная классификация:
Рисование полигонов на кросс-плоте для выделения областей
Присвоение классов выделенным точкам (например: "песчаник", "глина", "карбонаты")
Управление списком классов с настраиваемыми цветами
Управление разметкой:
Удаление отдельных полигонов
Отмена присвоения классов
Полная очистка разметки
Сохранение результатов:
Сохранение оригинального LAS-файла с добавленными кривыми классов (CLASS_0, CLASS_1 и т.д.)
Автоматическое сохранение меток классов в отдельном .npy файле

Библиотеки

Python 3.12+
PySide6 — кроссплатформенный GUI фреймворк (Qt6)
pyqtgraph — высокопроизводительная визуализация данных
numpy — научные вычисления
lasio — работа с LAS-файлами
Poetry — управление зависимостями и виртуальными окружениями
УСТАНОВКА

Требования:

Python 3.12\

Шаги:

Клонируйте репозиторий (или скопируйте файлы):
git clone https://github.com/your-username/seismictools.git
cd seismictools
Установите Poetry (если ещё не установлен):
pip install poetry
Установите зависимости и проект:
poetry install
Запустите приложение:
poetry run WLC

ИСПОЛЬЗОВАНИЕ

Нажмите "Загрузить" и выберите LAS-файл
Перейдите во вкладку "КРОСС-ПЛОТ" и выберите X/Y кривые
Нажмите "Построить кросс-плот"
Нажмите "Нарисовать полигон" и выделите область на графике
Перейдите во вкладку "КЛАССЫ", создайте новый класс или выберите существующий
Нажмите "Присвоить класс"
Повторяйте шаги 4–6 для других пластов
Нажмите "Сохранить LAS с классами" для экспорта результатов

ПРИМЕЧАНИЯ

Кривые классов сохраняются в LAS-файл с префиксом CLASS_
Метки классов дополнительно сохраняются в файл с расширением .labels.npy для быстрой загрузки при следующем открытии
Приложение автоматически загружает последний использованный файл при запуске
