# Seismic_Filtering_BP

# Что умеет данное приложение?:
- Загрузка одного или нескольких файлов формата "SEG-Y" (`.sgy`, `.segy`)
- Визуализация 2D сейсмограмм (трасса x время)
- Цифровая фильтрация в фоновом режиме:
  ~ Bandpass (диапазон частот)
  ~ Lowpass (верхняя граница)
  ~Highpass (нижняя граница)
- Настройка порядка фильтра и частот среза
- Сброс к исходным данным в один клик
- Запис и отображение событий и ошибок в реальном времени
- Многопоточная обработка — интерфейс не зависает

# Использование:
1. Скачать и установить Python версии 3.12.0 и выше по ссылке https://www.python.org/downloads/release/python-312/

2. Установить окружение poetry, для этого в cmd прописать путь до Python 3.12.0 и запустить команды:
```
%LocalAppData%\Programs\Python\Python312\python.exe -m pip install poetry
```

Пункты 1-2 выполняются один раз при запуске программы на новом устройстве. 

# При последующем использовании выполняются только шаги 3-5:

3. В командной строке перейти в директорию проекта. Пример:
```
C:                                             # Переходим на диск, где лежит проект (в данном случае диск C)                 

cd C:\seismictools\apps\Seismic_Filtering_BP   # Переходим в папку проекта
```
4. Для запуска программы в cmd прописать путь до Python 3.12 и запустить команду:
```
%LocalAppData%\Programs\Python\Python312\python.exe -m poetry run Seismic_Filtering_BP
```
