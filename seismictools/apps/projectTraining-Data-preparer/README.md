# TrainingDataPreparer

Инструмент для создания выборок по данным сейсмического куба. Позволяет загружать сейсмические данные в формате SEGY, визуализировать временные срезы в виде карты, выбирать точки на карте, просматривать соответствующие этим точкам сейсмотрассы, присваивать им метки классов (от 1 до 4) и сохранять размеченный dataset в формате .npz (а также есть export в .png самой карты с учётом нормализации и ещё .npy опять же с данными), пригодном для последующего анализа данных.

# Установка и настройка:

1. Скачать и установить Python версии 3.12.3 по ссылке https://www.python.org/downloads/release/python-3123/

2. Установить окружение poetry, для этого в cmd прописать путь до Python 3.12.3 и запустить команды:
```
%LocalAppData%\Programs\Python\Python312\python.exe -m pip install poetry

%LocalAppData%\Programs\Python\Python312\python.exe -m poetry install
```

Пункты 1-2 выполняются один раз при запуске программы на новом устройстве. 

# Запуск и использование:

1. Перейдите в папку проекта введя в командной строке:
```
cd C:\путь к проекту\SeismicTools
```
2. Запустите main данной ветки проекта командой:
```
%LocalAppData%\Programs\Python\Python312\python.exe -m poetry run training-data-preparer
```
3. В открывшемся интерфейсе:
- Укажите путь к файлу сейсмического куба (формат .sgy) и нажмите «Загрузить».
- Перемещайте ползунок «Временной срез T, мс», чтобы выбрать глубину просмотра.
- Кликните по интересной точке на карте — отобразится график трассы и добавится запись в таблицу.
- Нажимайте «Изменить класс», чтобы циклически переключать метку между классами 1 => 2 => 3 => 4 => 1. 
- При необходимости удалите трассу кнопкой «Удалить трассу».
- Нажмите «Сохранить выборку (X, Y)», чтобы экспортировать датасет в файл dataset.npz.
