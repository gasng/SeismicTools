# NMO_Worker
Приложения для поправок отражённых волн
# Запуск
1. Скачать и установить Python версии ">=3.12,<3.15" (https://www.python.org/downloads/)
2. Установить окружение poetry, для этого в cmd прописать путь до Python и запустить команды:
```
%LocalAppData%\Programs\Python\PythonXX\python.exe -m pip install poetry

%LocalAppData%\Programs\Python\PythonXX\python.exe -m poetry install
```
3. Войдите на GitHub и клонируйте ветку из репозитория.
```
git clone https://github.com/gasng/SeismicTools
git checkout feature/Grid-Worker
```

Пункты 1-3 выполняются один раз при запуске программы на новом устройстве. 
При последующем пользовании для запуска введите:
```
poetry run NMO_Worker
```
# Использование
Чтобы добавить сейсмограмму, нажмите кнопку обзор (поддерживает файлы .seg .segy)  
Чтобы отобразить сейсмограмму, выберите одну сейсмограмму из добавленных и нажмите загрузить  
Чтобы удалить путь из списка, нажмите кнопку очистить  
Чтобы построить скоростной спектр, нажмите кнопку скоростной спектр  
Чтобы отмечать точки на скоростном спектре, выберите режим пикировки  
Чтобы удалить последний пик, нажмите отменить пик  
Чтобы удалить все пики, нажмите очистить всё  
Чтобы перейти в режим обзора (недоступна пикировка), нажмите режим обзора
Чтобы построить сейсмограмму с применёнными поправками, нажмите поправки
