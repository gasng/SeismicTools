# First Break Picker

# Использование:

1. Скачать и установить Python версии 3.9.13 по ссылке https://www.python.org/downloads/release/python-3913/

2. Установить окружение poetry, для этого в cmd прописать путь до Python 3.9.13 и запустить команды:
```
%LocalAppData%\Programs\Python\Python39\python.exe -m pip install poetry

%LocalAppData%\Programs\Python\Python39\python.exe -m poetry install
```

Пункты 1-2 выполняются один раз при запуске программы на новом устройстве. 

# При последующем использовании выполняются только шаги 3-5:

3. Запустить программу 

4. В верхнем левом углу экрана переходим на страницу Settings
    В нижней части экрана выбираем функцию Upload, после чего находим и вывбираем необходимый нам фаил сейсмограммы
    Кнопка Clear удаляет график
    Кнопка load Picks подгружает на график уже существующие пики из соответсвующих json файлов
    На все той же странице Settings в поле Color Palet можно выбрать наиболее подходящую вам цветовую палитру для графика
    
5. После загрузки файла сейсмограммы, можно начинать работу по проставлению пиков
    В нижней части экрана на странице Plot Page можно выбрать тип пиков (Первые вступления, отраженная, преломленная - волны)
    Пики расставляются кликом левой кнопки мыши по графику, при проставлении следующего пика вдали от предыдущего, пики на трассах между ними интерпалируются по прямой (поэтому необходимо идти строго в выбранном направлении и не перескакивать между участками)

6. Посмотреть расставленные пики можно на странице Settings в таблице с пиками, там же можно удалить лишние или все сразу, а также сохранить их и экспортировать в json фаил.
